# Image Grid

A responsive image grid layout built with CSS Grid. A solution for **Beginner Project #8 (Image Grid)** from [roadmap.sh](https://roadmap.sh/projects/image-grid).

## Tech Stack

- **HTML5** - Semantic markup
- **Tailwind CSS v4** - Utility-first styling via CDN

## What I Learned

This project taught me how to use CSS Grid effectively for image layouts:

- **Grid template columns** - Using `grid-cols-2` and `md:grid-cols-3` to create responsive columns
- **Row spanning** - Using `row-span-2` to make images span multiple rows
- **Grid gaps** - Using `gap-4` for consistent spacing between grid items
- **Responsive design** - Switching from 2 to 3 columns at the `md` breakpoint
- **Grid item sizing** - Letting grid handle item sizing while controlling overall container width

I got help from AI (OpenCode) to understand how to structure the grid and use row spanning correctly.

## How to Run

No build tools needed. Just open `index.html` directly in a browser.

```bash
# Using a local server (optional)
npx serve .
```
